Everything in one interface.

01 / AUDIO

Sound → Click

Detect computer output audio and schedule a click after 1.5 seconds, with adjustable sensitivity and re-arm silence.

02 / TIMING

Random Timed Click

Start on a manual left-button release and click at a random time between 7.95 and 8.05 seconds later.

03 / MOTION

Red Ball Tracking

Follow a red circle at 0.2-second scan intervals, with a configurable 40 ms forward position estimate.

04 / IDENTITY

Blue Square Tracking

Follow originally blue squares even when they turn white, using Kalman prediction and identity association. Uncertain crossings are flagged.

Get started

Install and run on Windows.

STEP 1
Download the ZIP

Use the latest GitHub release. A Windows build must first finish successfully.

STEP 2
Extract all files

Keep the application EXE and its bundled support folder together.

STEP 3
Launch and choose a tool

Run MotionClickStudio.exe, configure a tab, and use Arm / Stop as needed.

Prefer the source? Install Python and run py -m pip install -r requirements.txt, then py app.py.

Technical notes

Clicks are timed on a best-effort basis under Windows. Vision tracking depends on display contents and processing speed, and identical objects can become impossible to distinguish during full occlusions. This application is open source and is not code-signed; examine the source before running it. The software itself does not transmit screen or audio data to any server.
